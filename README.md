Sistema de Gestão de Centro de Formação

Protótipo front-end de alta fidelidade para gestão de inscrições e área institucional de um centro de formação.

 Tecnologias
- HTML5, CSS3, JavaScript (Vanilla)
- Tailwind CSS (via CDN)
- Phosphor Icons
- LocalStorage (simulação de banco de dados)

Funcionalidades
- **Portal do Formando:** Catálogo de cursos, requisitos, contactos e formulário de pré-inscrição.
- **Painel da Secretaria:** Dashboard com KPIs, gestão de inscrições (confirmar/cancelar) e pesquisa.
- **Painel do Administrador:** Gestão de cursos, publicação de comunicados, edição de dados do centro e utilizadores.
Como testar
1. Clone o repositório.
2. Abra o ficheiro `index.html` no navegador (ou aceda ao link do GitHub Pages).
3. Navegue entre os 3 perfis (Formando, Secretaria, Admin) para testar a sincronização de dados.

 Nota
Este é um protótipo de demonstração. Os dados são guardados localmente no navegador (LocalStorage) e a versão de produção será integrada com backend em C# (ASP.NET Core) e base de dados SQL.
